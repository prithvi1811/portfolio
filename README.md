## 🛠️ Tech Stack

- **Framework:** [Next.js 14](https://nextjs.org/) - React-based framework for production apps
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) - Utility-first CSS framework
- **Animation:** [Framer Motion](https://www.framer.com/motion/) - Smooth, performant animations
- **Icons:** [Lucide React](https://lucide.dev/) - Clean, consistent icon library
- **Language:** TypeScript - Type-safe JavaScript development

## 🚀 Getting Started

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the portfolio live. Changes are hot-reloaded as you edit files.

### Building for Production
```bash
npm run build
npm start
```

### Linting
```bash
npm run lint
```

## 🚢 Deployment

This portfolio is designed for easy deployment on [Vercel](https://vercel.com/):

1. Push your changes to GitHub
2. Connect the repo to Vercel
3. Vercel automatically deploys on every push

For other platforms (Netlify, AWS, etc.), the standard `npm run build` and `npm start` commands work as expected.

## 📝 Customization

- **Update your info:** Edit `src/components/Resume.tsx` and `src/app/page.tsx`
- **Change colors:** Modify Tailwind config in `tailwind.config.ts`
- **Add/remove projects:** Update the projects array in `src/components/Projects.tsx`
- **Adjust animations:** Fine-tune Framer Motion settings throughout components
